# 方法演进：每一步针对什么问题

以下把归档中已有实验按逻辑关联重组。实验动机有文档记录；“机制可能是什么”的部分属于解释性假设。

## A：单 Agent LoRA 基线

**问题：** 单模型能否完成结构化报告生成？

**设计：** 使用 Qwen2-VL-2B-Instruct 做 LoRA 微调，直接输出报告。

**观察：** TED 子集最终报告体征 F1 为 0.462。它提供报告生成起点，没有可单独评价的专科状态。

**下一步理由：** 需要把证据提取与报告生成拆开，检查中间环节。

## B：朴素多 Agent 链路

**假设：** 对同一基座做角色化任务监督，先生成眼科和临床状态，再生成报告，可以帮助组织信息。

**设计：** 一个病例展开为眼科状态、临床状态和报告三个训练任务；链式评估使用模型生成的中间状态，而不是把参考状态直接交给报告角色。

**观察：** 眼科状态 F1 为 0.133，最终报告 F1 为 0.706，不一致比例为 0.477。

**解释边界：** 结果显示状态与报告之间存在差距。“报告角色绕过了状态”是合理的机制假设，但缺少输入屏蔽或反事实干预，不能仅靠指标确认模型内部行为。

## C1：隐藏眼科标签与阳性重采样

**问题：** 状态预测过于保守，且眼科输入含诊断标签可能形成捷径。

**设计：** 训练时隐藏眼科角色的诊断标签，并将含阳性体征的眼科样本重复采样。公开主结果使用推理时也隐藏眼科标签的严格版本。

**观察：** 严格版本眼科状态 F1 为 0.778，报告 F1 为 0.836，不一致比例为 0.205。

**限制：** 同时改变了标签可见性和重采样，不能分别估计两项改动的效果；基线文本仍可能包含体征。隐藏标签不等于纯图像识别。

## C2：稀有体征增强

**问题：** C1 的结膜水肿状态 F1 为 0。

**设计：** 增强稀有体征样本，记录中的权重包括阳性眼科重复 3、结膜水肿重复 5、眼睑退缩重复 2、hard negative 重复 2。

**观察：** 结膜水肿状态 F1 为 0.333；整体状态 F1 为 0.765，最终报告 F1 降为 0.607。

**下一步理由：** 增加某种体征的训练存在感，并不保证最终报告改善。需要同时检查精确率、召回率与跨阶段一致性。

## C3：状态约束报告训练与一致性任务

**设计：** 结合 state-grounded 报告目标、consistency critic 训练任务和评估时的严格 grounding 提示。critic 是附加训练任务，不应描述成已验证的独立线上裁判。

**观察：** 最终报告 F1 为 0.847，状态 F1 为 0.776，不一致比例为 0.227。非 TED 阳性体征出现比例升至 0.867。

**限制：** 多项改动一起引入，无法独立归因；C3 比 C1 报告 F1 高 0.011，没有统计显著性证据。

## C3-filtered：后处理接受规则

**设计：** 将报告中提取的阳性体征，与眼科状态的 present 取交集。

```text
accepted_positive = report_positive AND state_present
```

**观察：** 报告体征 F1 为 0.776，TED 子集不一致比例为 0，非 TED 阳性体征出现比例为 0.667。

**限制：** 这是体征级解释规则，原始自由文本没有被重写。该规则只保证接受的报告阳性受到状态支持，不能一般性地保证报告与状态完全相同。

## C4：非 TED 负样本增强

**设计：** 使用针对非 TED 的保守报告目标，重复非 TED 报告训练样本，要求不把风险因素直接转为阳性视觉体征。

**观察：** 最终报告 F1 为 0.667，不一致比例为 0.341，非 TED 阳性体征出现比例为 0.733。

**复盘：** 这一配置没有得到理想综合表现，可作为负面消融保留。它不能证明所有负样本训练都无效，也不能证明过滤在任意任务上都优于训练改进。
