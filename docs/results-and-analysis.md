# 汇总结果与取舍

## 主结果：严格版本边界

| 模型 | 关键词数量代理分 | 状态 micro-F1 | 报告 micro-F1 | 不一致比例 |
|---|---:|---:|---:|---:|
| A | 0.867 | — | 0.462 | — |
| B | 0.896 | 0.133 | 0.706 | 0.477 |
| C1-strict | 0.894 | 0.778 | 0.836 | 0.205 |
| C2 | 0.908 | 0.765 | 0.607 | 0.273 |
| C3 | 1.000 | 0.776 | 0.847 | 0.227 |
| C3-filtered | — | 0.776 | 0.776 | 0.000 |
| C4 | 0.888 | 0.766 | 0.667 | 0.341 |

体征 F1 与不一致比例在 11 条 TED 子集上计算，关键词数量代理分来自报告评价。C1-strict 固定使用隐藏眼科标签的后期评估版本。A 没有眼科状态；过滤后的关键词代理分未重新计算，故留空。

## 怎样解读

### B 与 C1：中间状态发生了较大变化

B 的状态 F1 0.133、报告 F1 0.706，提示不能只评价最终文字。C1-strict 的状态 F1 0.778、不一致比例 0.205，说明当前组合策略在这一小样本上改善了所测的状态和一致性。

C1 同时改变了多个训练因素，没有单独消融。因此，“标签隐藏让模型真正学会看图”超出了当前证据。

### C2：局部目标改善不等于端到端改善

结膜水肿状态 F1 从 0 提至 0.333，但报告 F1 只有 0.607。不能只用稀有体征召回或文本相似度挑选最终方案。

### C3：最高报告 F1 不代表整体最优

C3 的报告 F1 0.847 比 C1-strict 0.836 高 0.011，而不一致比例为 0.227，未低于 C1-strict。内部负控聚合也显示较多阳性体征出现。这里的“最高”仅指当前表格的点估计，不表示统计显著优势。

### C3-filtered：精确率与召回的交换

C3 同一过滤分析中的体征级 micro precision/recall 由 0.806/0.893 变为 0.905/0.679，F1 由 0.847 变为 0.776。过滤压掉不受状态支持的报告阳性，也继承了状态漏检。

原文没有被重写；观察到的不一致比例 0 仅针对过滤后的四种体征判断。解析规则也与更早体征脚本略有差异，不能把所有差异归因于模型。

### C4：保留负面消融

C4 的报告 F1 为 0.667，不一致比例为 0.341。负控代理出现比例为 0.733，较 C3 的聚合值低，但未形成理想的综合取舍。

这支持“当前负样本增强设置需改进”，不支持“任何负样本增强都不如后处理”。

## 选择怎样表述

归档中将 C1 定位为较均衡的候选，C3 为报告 F1 较高的变体，过滤模式为接受策略，C2/C4 为消融。公开复盘保留这些研究角色，不把它们写成临床使用推荐。
