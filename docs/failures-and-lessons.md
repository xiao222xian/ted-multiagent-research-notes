# 失败经验与方法判断

## 报告得分可以掩盖状态质量

B 的报告 F1 为 0.706，状态 F1 为 0.133。最终输出比较像参考答案，并不说明每个中间角色都有有效贡献。

应增加去掉某个角色、屏蔽某类输入或替换状态的干预。已有结果只支持提出“证据链可能被绕过”的问题，不足以证明具体内部机制。

## 重采样不是免费提升

C2 把结膜水肿状态 F1 从 0 提到 0.333，但报告 F1 从 C1 的 0.836 降为 0.607。后续应同时检查稀有体征的精确率、召回率以及报告传播影响，而不是只看该体征是否开始输出。

多种重采样权重一起改变，也妨碍独立归因。

## 状态约束提示不保证模型服从

C3 组合了状态约束训练与严格提示，仍观察到不一致比例 0.227。自然语言要求和训练目标不是确定性约束。

对于必须执行的接受条件，可以在输出解释层明确实现，并同时记录丢掉多少正确阳性。它仍然依赖上游状态质量。

## 负样本增强的当前配置没有奏效

C4 相对 C3 的报告 F1 由 0.847 降为 0.667，不一致比例由 0.227 升为 0.341。较低的训练损失也没有带来所关心指标的全面改善。

这个结果值得保留，但结论限于当前设置；不能把它扩展为“负样本训练没有价值”。

## 安全层也会继承状态漏检

过滤后，报告体征 precision 从约 0.806 提升到 0.905，recall 从约 0.893 降到 0.679。只接受状态支持的体征，会压掉一部分错误阳性，也会压掉状态漏检而报告原本提到的正确阳性。

因此，过滤适合被讨论为可审计的接受策略，不能在未经验证时宣称是临床安全保障。

## 复盘时发现评价命名比模型排名更重要

“FP”实际上可能只是非 TED 样本中体征的出现；“clinical score”可能只是关键词命中数量比；“冲突”可能同时包含额外阳性和漏报。

先明确分母、参考标签、解析器与输入信息，再谈哪一个版本更好。本次公开整理保留数值，同时收窄这些命名与结论。
