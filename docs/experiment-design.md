# 实验设计与版本边界

## 数据与划分

记录中的主实验使用 101 条训练病例和 26 条留出病例。体征分析进一步区分 11 条 TED 与 15 条非 TED。

角色展开及重复采样生成更多训练样本，但这些样本不是新增独立病例：

| 版本 | 展开/重采样后的训练样本 | 验证任务样本 |
|---|---:|---:|
| C1 | 471 | 78 |
| C2 | 546 | 78 |
| C4 | 694 | 104 |

这些数值记录任务级样本量，不应用于声称拥有同等数量的独立患者。现有材料不足以在公开版本确认患者级去重和跨划分泄漏排查已经通过。

## 共享设置

基座为 Qwen2-VL-2B-Instruct，使用共享基座与 LoRA 进行角色任务监督。多 Agent 变体记录的主要训练参数为：2 epochs、学习率 2e-4、LoRA rank 16、batch size 1、梯度累积 4。

这些是已有记录，不是已验证可复现的完整配置。公开版不包含权重、训练数据和逐次运行日志，因此无法仅凭本仓库重跑原实验。

## 对照关系

| 对照 | 希望回答的问题 | 不能单独识别的因素 |
|---|---|---|
| A vs B | 引入角色化状态后，结果发生什么变化 | 任务样本数、训练预算与提示变化 |
| B vs C1 | 隐藏眼科标签并增强阳性状态后是否改善 | 隐藏标签与重采样的各自贡献 |
| C1 vs C2 | 稀有体征权重是否改善识别 | 权重变化对其他体征与报告的耦合 |
| C1 vs C3 | 状态约束训练组合的表现 | 训练目标、critic、推理提示的各自贡献 |
| C3 vs filtered | 接受规则如何改变提取出的体征结果 | 未验证自由文本重写后的完整质量 |
| C3 vs C4 | 当前负样本增强配置的取舍 | 负样本构造与重复次数的独立贡献 |

## C1 的评估版本

旧训练报告中保留了一个 C1 评估结果：状态 F1 0.755、报告 F1 0.821、不一致比例 0.250。后续严格隐藏眼科标签的比较表使用 0.778、0.836、0.205。

本仓库主表固定采用后者，不把前者的 clinical score 0.933 与后者的其他指标拼成一行。两版结果不应仅凭名字相同而合并。

## 标签暴露仍然存在

核对评估代码发现，隐藏标签开关作用于眼科 prompt；临床角色与报告角色的 common prompt 仍包含诊断标签。因此，这组结果不是完全去标签的端到端诊断性能。报告中 TED 诊断词的出现率尤其不能解释为独立诊断能力。

## 结果分表的原因

主结果来自后期比较表；负控汇总来自另一份聚合报告。后者没有记录完整运行路径与全部提示开关，无法只用聚合文件确认每个同名模型与主表完全对应同一次评估。公开版分表保存，不默认做严格配对的跨表比较。

重复查看和据留出集调整方案，也可能使其承担开发验证集角色。未来需要新的独立测试集。
