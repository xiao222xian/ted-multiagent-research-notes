## 哪些内容没有发布

- 患者照片、临床表格、病史、逐例状态或医疗报告、病例标识。
- 原始数据、模型权重和含内部上下文的训练/推理日志。
- 合作人员信息、内部讨论、服务器地址与本机绝对路径。
- API 配置、凭据、旧 Git 历史与私密仓库链接。
- 原论文全文、文献 PDF 和第三方参考项目源码。

不提供真实病例改写的公开样例。聚合指标经过人工审阅和脚本检查，仍应结合小样本、指标定义与复现限制阅读。
