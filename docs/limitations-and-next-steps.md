# 局限与后续验证

项目已经结项，以下是研究建议，不表示这些工作已开展或会自动继续。

## 当前证据的边界

- **样本量小。** TED 体征主结果来自 11 条病例；四个体征存在病例内相关性，不能把 44 个决策当作 44 名独立患者。
- **没有显著性结论。** 无多随机种子重复、置信区间或正式配对检验，0.011 的 F1 差异不能表述为确定提升。
- **留出集用于多轮迭代。** 可能形成验证集选择偏差，最终测试需要全新隔离数据。
- **标签仍进入部分角色。** 当前链路不是盲诊断；基线文本也可能暴露体征信息。
- **参考状态与文本规则有限。** 没有在此次整理中新增独立医生标注；否定、条件句、建议句和不确定表达可能解析错误。
- **非 TED 并非逐体征阴性。** 当前负控代理指标不能直接证明真实误报率。
- **过滤只改变体征接受结果。** 未证明原报告全文已被修复，也未对过滤后全文重新评分。
- **未证实独立外部验证。** 记录中有外部负控准备计划，但没有完成的外部推理结果。
- **复现材料不完整公开。** 无原始数据、权重、完整运行配置或日志，读者不能从聚合表重建实验。
- **不声明伦理审批已获核验。** 公开材料不足以确认数据授权、审批和临床部署许可；本仓库不据此作任何认证性表述。

## 如果未来恢复，优先顺序

1. 固定输入可见性、prompt、分组规则、解析器版本和运行标识；确认主表与负控表来自同一套输出。
2. 做患者级去重，区分开发验证集与最终独立测试集。
3. 重新标注非 TED 的逐体征真值，把“体征出现比例”与真实 FP 分开。
4. 将隐藏标签、阳性重复、critic、训练 grounding 和推理提示分别消融，匹配训练预算。
5. 用新的外部数据检验，并在患者级做不确定性估计；避免只报告最佳一次运行。
6. 若要生成可用全文，明确重写规则并重新评估否定、诊断提示和建议内容，而非仅过滤提取结果。
7. 最后再评估医生审阅、部署流程和真实使用风险。

这些步骤的目的，是把目前的探索性发现转为可检验的证据，而不是延长模型版本列表。
